# 新增登录和注册界面

## Goal

为管理后台项目添加登录和注册界面，使用户能够通过表单进行身份验证，访问受保护的页面。

## What I already know

* 这是一个React + TypeScript + Vite + Tailwind CSS v4项目
* 使用React Router v7进行路由管理
* 项目是管理后台（starter-dashboard）
* 当前路由：Dashboard、Users、Orders、Products、Settings
* 没有现有的认证相关代码

## Assumptions (temporary)

* 需要创建登录和注册表单UI
* 需要添加路由保护，未登录用户重定向到登录页
* 使用模拟认证逻辑（本地状态管理，适合原型开发）

## Requirements (evolving)

* 创建登录页面（表单：邮箱/用户名、密码、记住密码选项）
* 创建注册页面（表单：用户名、邮箱、密码、确认密码）
* 表单验证（前端验证）
* 路由保护：未登录用户只能访问登录/注册页面
* 登录成功后重定向到Dashboard
* UI设计：简洁现代风格，使用现有Tailwind CSS组件，保持与项目其他页面一致
* 未登录用户访问受保护页面时重定向到登录页，登录后返回原页面
* 记住密码功能：登录时记住用户名/邮箱，下次自动填充
* 表单加载状态：登录/注册按钮显示加载动画，防止重复提交
* 错误提示优化：友好的错误提示，如密码错误、用户已存在等
* 退出登录功能：提供退出登录按钮，清除登录状态
* 用户状态显示：在导航栏显示当前登录用户信息
* 权限管理：基于用户角色的页面访问控制（简单角色：admin/user）
* 网络错误处理：登录/注册失败时的错误提示
* 并发请求处理：防止重复提交
* 会话过期处理：登录状态过期后的处理
* 密码强度要求：最少6位字符

## Technical Notes

* 使用React Router v7的ProtectedRoute模式
* 认证状态使用React Context管理
* 表单验证使用自定义hook
* UI组件使用现有的Tailwind CSS v4样式系统
* 记住密码功能使用localStorage存储
* 模拟认证逻辑使用本地状态管理
* 用户角色使用简单枚举（admin/user）
* 退出登录功能清除Context状态和localStorage
* 导航栏显示当前用户信息
* 权限控制使用ProtectedRoute的role参数
